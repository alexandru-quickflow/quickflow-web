# quickflow-web

The Quick Flow website: portfolio and services, in Romanian and English.

Approved spec: `docs/spec.md` (v2). It is frozen. Anything not in it is a change
request, recorded in
`D:\Google Drive\work\Projects\quickflow\04-change-requests.md`.

Stack decisions: `docs/anexa-tehnica.md` and `docs/adr/`.
Astro framework guidance: `AGENTS.md`, generated by the scaffold. Do not
duplicate it here.

## Project rules

- **Static, no client framework.** The only interactive element is the contact
  form. Do not add React, Vue or Astro islands. If something seems to need one,
  ask first. See ADR-0001.
- **The form works without JavaScript.** A plain POST to `/api/contact`, with JS
  only as an enhancement.
- **i18n**: Romanian with no prefix, English under `/en`. Every page exists in
  both languages, with equivalent content, not an abridged version.
- **Romanian copy**: comma-below diacritics, never cedilla. No em dashes in any
  delivered text, in either language.
- **Secrets** live in the Cloudflare Pages project environment and in local
  `.dev.vars`. Never in the repository.
- **Images** go through Astro's `<Image>` component, AVIF and WebP.
- **Icons** come from `astro-icon` with the `ph` (Phosphor) set.

## Non-negotiable criteria

From the spec, sections 1 and 4:

- LCP under 1 second on mobile, measured with Lighthouse in PageSpeed Insights
  against the production URL
- Every page has its own title and meta description, in both languages
- Analytics stays cookieless, so there is no cookie banner. Adding Google
  Analytics or Meta Pixel would make a banner mandatory and would break the spec

## Configuration that is not in this repository

Cloudflare dashboard, and therefore not restored by a deployment:

- Rate limiting rule on `/api/contact`, 5 requests per hour per IP (ADR-0003)
- Web Analytics token (unset on purpose, see ADR-0006)
- Analytics Engine binding `PAGEVIEWS` and Fail open, for the page view counter
- Environment variables: Resend API key, Turnstile secret key
